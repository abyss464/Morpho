# COCO pair ingest script

Ingests COCO-accepted (image, sentence) pairs from `ops/logs/coco-accepted.json`. For each pair: uploads the photo as an image candidate, mints the caption as an example candidate with byte-offset highlight, selects the image as the live image (human override, pinned), and selects the caption into example slot 1. Sequential, one pair at a time, via the admin API. Pairs without a valid whole-word lemma match or missing image file are skipped.
