# Progress Sync

The Android side of the progress sync with the web app (docs/contracts/sync.md). The web app's server merges; this sends the local version-1 document and applies the merged document it gets back. Today's counters, `daily_stats` and settings stay local.

## SyncFailure (enum)

Why a sync did not go through:
- **BAD_ADDRESS** — what was typed is not an http(s) address
- **UNREACHABLE** — no connection: no network, no route, unknown host, connection reset
- **REFUSED** — the host answered, but nothing listens on that port
- **TIMED_OUT** — connecting took over 5 s or the reply over 15 s
- **SERVER_ERROR** — the web app answered with a non-2xx HTTP status
- **BAD_REPLY** — the reply is not a version-1 document

## SyncOutcome

- **Done(updated, sent)** — words changed here from the web; words sent to the web
- **Failed(reason, address, status)** — the reason, the address tried, and the HTTP status for SERVER_ERROR

## ProgressSync(store, settings)

Syncs run one at a time (a mutex).

### last (StateFlow)
The most recent outcome in this run of the app, or null before the first. Settings shows it, whether it came from Sync now or from Today's silent sync.

### syncWith(address) -> SyncOutcome
Normalizes the address, saves it as the sync address, and syncs with it. An address that does not normalize gives BAD_ADDRESS and is not saved.

### syncSaved() -> SyncOutcome or null
Syncs with the saved address; null when none is saved.

### A sync
1. Exports the local document from user.db: every word with an FSRS card or a stream stage, keyed by word id. Cards map field for field, times as ISO-8601 UTC to the millisecond, `state` 0–3. Stages carry `stage` and `next` as lowercase names, `immediate`, `needClean`, `thenUse`, `flawed`, and never `since`. Notes carry their text and time.
2. POSTs it as JSON to `<address>/api/sync` (HttpURLConnection, 5 s connect timeout, 15 s read timeout) and decodes the reply, ignoring unknown fields.
3. Reads the stream again and applies the merged document (contract §4) in one transaction:
   - a word counts as changed when its merged card or stage differs from the local one (times compare as instants, so the date format does not matter);
   - for a changed word: the card is set to the merged card; the stage is replaced by the merged stage, starting its spacing at the current stream position (`since` = `seq`), or removed when the merged stage is null; the step on screen and the last review are dropped when they are for that word;
   - a merged note newer than the local one replaces it;
   - an entry that cannot be read (unknown stage or step name, a `review` next step, a bad date) is skipped and logged.
   Nothing is written when no word and no note changed.
4. Returns Done with the changed-word count and the number of words sent.

Network failures map to SyncFailure. Android's HTTP stack reports every failed connect as "Failed to connect to …"; after one, a plain socket connect to the same host and port tells REFUSED (ECONNREFUSED) from UNREACHABLE.

### DEFAULT_ADDRESS
`http://127.0.0.1:30017`: the web app on the computer, reached over `adb reverse tcp:30017 tcp:30017`.

### normalizeAddress(input) -> address or null
Trims the input and its trailing slashes and adds `http://` when no scheme is given ("192.168.1.5:30017" -> "http://192.168.1.5:30017"). Null when the result is not an http or https URI with a host.
