# Progress Repository

Read/write access layer for user.db. Progress rows are never deleted — when a future release removes a word, its rows are only disassociated from release.db; if the word is published again later, its FSRS state is restored exactly as before.

## Learning ladder rows

### inFlightWordIds() -> word id list
Words the learning-ladder engine left mid-ladder (`learning_progress` status `learning` with at least one round passed). Read once, when the stream starts without a saved state.

## FSRS card

### allCards() -> card list
All FSRS scheduling cards.

## Daily Statistics

### statsFor(date) -> stats or null
Queries the statistics row for the date.

### recentStats(limit) -> stats list
Recent daily statistics, at most 400 by default, newest first.

### upsertStats(row)
Writes one day's statistics row.

## Stream step

### recordStep(changed, delta, metaRows)
Writes one finished stream step in a single transaction: the changed FSRS cards, the counts of [delta] folded into its day's row (a delta of all zeros leaves `daily_stats` alone), and the meta rows that hold the stream state.

## Metadata

### metaValue(key) -> value or null
Reads a key value from the meta table.

### setMeta(key, value)
Writes a key value to the meta table.

### ensureInitialised(contentVersion)
Ensures user.db metadata is initialised: writes the current schema version, sets the default daily goal (if not yet set), and records the content version. Completed in a transaction.

### clearAll()
Clears all tables. Completed in a transaction.
