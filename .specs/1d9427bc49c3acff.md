# Greeting Header

The masthead of Today.

## GreetingHeader(greetingPeriod, streakDays, onOpenSettings, modifier)

- greetingPeriod: morning / afternoon / evening, which picks the greeting
- streakDays: consecutive study days; above 0 a streak badge ("12 days") shows on the right
- onOpenSettings: called when the settings button is tapped

### Layout

Left, stacked: the greeting in tracked uppercase, the wordmark "Morpho" in Garamond, and the icon's four marks beneath.

Right, in a row: the streak badge (when there is a streak) and the settings button.
