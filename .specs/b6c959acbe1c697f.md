# Commons ingest script

Ingests Wikimedia Commons search-accepted (image, caption) pairs from `ops/logs/commons-accepted.json`. For each pair: uploads the image as a candidate, mints the caption as an example candidate with byte-offset highlight of the matched form, selects the image as live, and selects the caption into example slot 1. All mutations via admin API.
