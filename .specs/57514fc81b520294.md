# WIT preparation script

Matches Wikipedia Image Text (WIT) pairs to gap words. Reads `/tmp/wit_gap_matches.json` and `/tmp/stock_only_words.tsv` for current word_ids. Downloads images from Wikimedia Commons URLs, converts to WebP. Outputs `ops/logs/wit-accepted.json` (input for `wit_ingest.py`) and downloads into `/tmp/wit/webp/`.
