# Visual Genome ingest script

Ingests VG-accepted (image, caption) pairs from `ops/logs/vg-accepted.json`. For each pair: uploads the cropped region image as a candidate, mints the VG caption as an example candidate with byte-offset highlight, selects the image as live (human override, pinned), and selects the caption into example slot 1. Sequential, via admin API. Skips pairs without a valid whole-word lemma match or missing image file.
