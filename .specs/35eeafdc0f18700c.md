# Morfessor Adapter CLI

Console entry point for the corresponding command `morfessor-adapter` (run via `uv run --project adapters/morfessor`).

## main() -> exit code

Uses the adapter name "morfessor" and calls the common protocol layer's run() via the operation registry, obtaining the exit code and then directly calling sys.exit.
