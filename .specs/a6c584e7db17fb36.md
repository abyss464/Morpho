# Stream Store

Persistence of the stream (docs/contracts/stream.md) inside user.db without a schema change: the stream state and the learner's notes are JSON values in the `meta` table (`stream_state`, `stream_notes`), so they ride along with Auto Backup and the manual export.

## WordNote

The learner's own explanation of a word: its text and when it was written.

## StreamSnapshot

Everything the stream engine reads: every shipped word id in release learning order, every FSRS card by word id, and the stream state.

- **unitOf(wordId)** — 1-based unit of the word, 20 words per unit in learning order
- **positionOf(wordId)** — the word's learning-order position, or -1 when the release does not ship it
- **UNIT_SIZE** — 20

## StreamStore(progress, content)

### open(today) -> StreamSnapshot
Loads the learning order, every card and the stream state. With no saved state (or an unreadable one) it builds a fresh state for [today] and saves it: words with an FSRS card stay in review, and words the old learning ladder left mid-way (`learning_progress` status `learning` with rounds passed > 0, shipped, no card) become Learning with a delayed `explain2` next.

### save(state)
Writes the stream state.

### record(result, date)
Writes a finished step in one transaction: the cards it changed, the day's `daily_stats` counts (`new_learned` += graduated, `reviewed` += reviewed, `answer_count` += graded, `correct_count` += clean), and the new stream state.

### notes() -> word id to WordNote
The saved notes; empty when none or unreadable.

### saveNote(wordId, text, now) -> all notes
Saves the trimmed text as the word's note, replacing an earlier one.
