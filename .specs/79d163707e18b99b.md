# Morfessor Models and Segmentation

Core logic for model loading, ad-hoc training (wave-1 stopgap), and batch segmentation.

Pre-trained models are stored under `adapters/morfessor/model/`, supporting `.bin` / `.model` / `.gz` formats. A custom path can also be specified via the environment variable `MORPHO_MORFESSOR_MODEL`. When no pre-trained model is available, a one-time Baseline model is trained on the current batch on the fly — the segmentation results are crude but usable, serving only as a fallback for word sources, not as a reference answer.

Ad-hoc training has three safeguards: a fixed random seed ensures determinism; `model_ver` embeds a digest of the training vocabulary and hyperparameters to keep versioning honest; if the vocabulary is too small or the average morpheme length is too short, guessing is refused and the input is returned unsegmented as-is.

## LoadedModel

Container for an already-loaded model, holding the model object and the `model_ver` string.

## Segmentation

Container for segmentation results, holding the segmentation mapping (word -> morpheme list), `model_ver`, and a source tag (pretrained / adhoc / unsegmented).

## library_version() -> string

Returns the installed version number of the Morfessor library.

## model_dir() -> path

Returns the model directory path.

## find_model_file() -> path or empty

Looks for a model file. The environment variable takes precedence; otherwise, the first matching file in the model directory ordered by name is used.

## segment_batch(words) -> Segmentation

Segments a deduplicated, order-preserving batch of words. Uses the pre-trained model if available; otherwise trains on the fly. Before training, the vocabulary size is checked against the threshold; after training, the average morpheme length is checked for reasonableness. If either check fails, unsegmented results are returned.

## mean_morph_chars(segments) -> float

Computes the average number of characters across all morphemes in the segmentation results.

## segment_word(model, word) -> string list

Segments a single word. If the word is in the vocabulary, the training result is returned directly; otherwise, Viterbi analysis is used. After segmentation, it verifies that concatenating the morphemes reproduces the original word; if not, a `PermanentError` is raised.

## adhoc_tag(training, morph_length, max_epochs) -> digest string

Hashes the training vocabulary and hyperparameters into a short digest, used for `model_ver`, ensuring models trained from different vocabularies or hyperparameters are not confused.

## Environment Variables

- `MORPHO_MORFESSOR_MODEL` — specifies the path to a pre-trained model
- `MORPHO_MORFESSOR_MAX_EPOCHS` — maximum epochs for ad-hoc training (default 8)
- `MORPHO_MORFESSOR_MORPH_LENGTH` — target average morpheme length (default 5.0)
- `MORPHO_MORFESSOR_MIN_VOCAB` — minimum vocabulary size for ad-hoc training (default 100)
