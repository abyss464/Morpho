# Visual Genome preparation script

Matches VG region descriptions to gap words, ranks by description quality (length, specificity, concreteness), selects the top candidate per word, crops images to region bounding boxes, and converts to WebP. Reads VG `region_descriptions.json`, `gap_words.tsv`, and downloaded VG images. Outputs `ops/logs/vg-accepted.json` (input for `vg_ingest.py`) and a coverage analysis report.
