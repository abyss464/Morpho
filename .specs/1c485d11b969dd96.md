# COCO revert and re-import script

Reverts COCO example candidates minted with client-computed byte offsets and re-mints them through the engine's server-side offset recomputation. For each COCO entry: rejects the old candidate, purges it, mints an identical-text replacement, and re-selects into slot 1. Also verifies image selections still point at each word's COCO upload. Ground truth is `ops/logs/coco-accepted.json`.
