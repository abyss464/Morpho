# Navigation Graph

Defines the routes and the Compose NavHost: Today, the stream, settings, a looked-up word.

## Route Constants (MorphoRoutes)

- **TODAY** — Today, the start destination
- **STREAM** — the stream
- **SETTINGS** — settings
- **WORD** — a looked-up word, `word/{id}`; `word(id)` builds the route

## MorphoApp(container, startup, navController?)

Top-level Composable that receives the dependency container and startup report. Shows a loading animation while startup is empty; renders the navigation graph once ready.

Page transitions use shared-axis animation, with forward and backward directions reversed.

### Page Flow
- Today opens the stream, settings and a looked-up word
- The stream returns to Today on pause and on "Done for today", popping back to Today
- Settings and the word page return by popping
