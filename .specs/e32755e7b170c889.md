# Settings ViewModel

All setting changes take effect immediately: the corresponding manager is updated in the same call as persistence, and toggle-type settings also play an effect once so the user perceives it right away.

## Exposed State

### settings
A live stream of user settings, sharing the same StateFlow as SettingsRepository.

### backup (BackupUiState)
UI status of backup/restore operations:
- **busy** — currently executing import/export
- **pending** — a backup file has been staged and awaits confirmation
- **message** — operation result message (export success with byte count / export failure / file rejected with reason / import failure)

### syncAddress
The address field's text: the saved sync address, else the default `http://127.0.0.1:30017`.

### syncing
True while a sync started here runs.

### syncOutcome
The last sync's outcome in this run of the app, from Sync now or from Today's silent sync; null before the first.

## Accepted Operations

### setSyncAddress(value)
Updates the address field. Nothing is saved until a sync.

### syncNow()
Tap feedback, then saves the address and syncs with it. The field then shows the address as saved (scheme added, trailing slash dropped), unless it was edited during the sync; text that is not an address stays as typed. Ignored while a sync runs.

### setDailyGoal(value)
Sets the daily new-word goal, aligned to a multiple of the step size, with a tap for each step the slider passes.

### setSoundEnabled(value)
Toggles sound effects, with a haptic tick; plays a confirmation sound when turned on.

### setSfxVolume(value)
Adjusts the SFX volume. Plays the tap at the new volume each time the slider crosses a tenth.

### setHapticsEnabled(value)
Toggles haptic feedback, with the tap sound; triggers a level-up vibration when turned on.

### setReducedMotion(value)
Toggles reduced motion, with tap feedback. A null value means follow the system.

### setActivityChartStyle(value)
Switches the activity chart style, with tap feedback.

### onTap()
Tap feedback for presses that open something: the file pickers.

### setThemeMode(value)
Switches the theme (light/dark/follow system). The app redraws immediately upon switching.

### suggestedExportName() -> file name
Returns the suggested export file name.

### onExportTarget(uri)
Called after the user selects an export target; performs the export. Plays a completion sound on success.

### onImportSource(uri)
Called after the user selects an import file. It only stages and validates, without writing immediately; once validation passes, pending becomes non-null, awaiting confirmation.

### cancelImport()
Cancels the pending import and cleans up the staged file.

### confirmImport()
Confirms the import, replaces the database, and restarts the app. On success the app restarts directly, with no further status.

### dismissMessage()
Dismisses the operation result message.
