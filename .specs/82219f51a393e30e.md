# Fixed Size Tokens

Fixed component sizes, via `MorphoTheme.sizes`:

- audioChip (44) / audioChipSmall (36) — audio playback button
- shakeAmplitude (8) — wrong-pick shake amplitude
- sharedAxisSlide (30) — step transition slide distance
- primaryButton (52) — height of a primary pill button
- trackHeight (4) — thin progress tracks: journey and unit bars
- streamBarHeight (6) — today's progress bar on the stream
- wordOption (56) — a word option in the use step
- thumbnailWidth (72) / thumbnailHeight (54) — the picture beside the first explain question
- blankWidth (64) — an open blank in the explain step's sentence
- coverHeight (160) — the covered picture of a review question
- resultPictureHeight (190) — the picture on a review result
