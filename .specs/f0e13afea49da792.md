# Word Pattern

## isJsSpace(c) / jsSpaces
JavaScript's whitespace (`\s`, `String.trim`): ASCII spaces plus the Unicode space separators, line separators and the byte-order mark, so text splits and trims exactly as on the web.

## wordPattern(word) -> Regex or null
The headword and its regular forms inside running text, case-insensitively, as whole words: the lemma, +s/es/ed/d/ing/'s; e-final stem + ing/ed; y-final stem + ies/ied; a doubled final b d g k l m n p r t + ed/ing. A multi-word headword matches with any run of spaces between its words. Word boundaries are ASCII letters, digits and underscore, as JavaScript's `\b`. Null for a blank word.
