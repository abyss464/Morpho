# Morfessor Word Segmentation Operation

`morfessor.segment` operation implementation — a single process handles batch word segmentation.

## OP_SEGMENT

Operation name constant, value "morfessor.segment".

## segment(params) -> dictionary

Extract the "words" string list from params, clean and deduplicate, then pass to the model layer for batch word segmentation. Returns `{"segments": word-to-morpheme list mapping, "model_ver": model version}`. Batch limit is 5000 words.

## OPS

Operation registry that maps OP_SEGMENT to the segment handler function.

## Constraints

- Single batch must not exceed 5000 words
- Each word must not exceed 64 characters
- Whitespace-only words are treated as errors
