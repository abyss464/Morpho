# Activity Heatmap

A grid in the manner of a contribution graph: colour intensity shows how much was studied each day.

## ActivityHeatmap(data, modifier)

- data: heatmap data — each cell's date and intensity level (0-4), the number of weeks, and the largest day's activity (graded steps answered)

### Display

On the left is the weekday label column (M, W, F carry text, the rest are blank); on the right is the grid of cells. Each column is one week (7 rows) and the grid scrolls horizontally.

Colour deepens with the level: level 0 is the empty ground, levels 1-2 use the mist base colour with rising opacity, levels 3-4 use the copper highlight.
