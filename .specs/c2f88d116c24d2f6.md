# Domain-to-Presentation Layer Mapping

## WordBundle.toWordDetail() -> WordDetail

Converts the word package in the domain model into the presentation model required for the detail overlay. It does three things: takes the data's byte offset and converts it to a Kotlin character range (used for example highlighting), parses the word source's segmented JSON into a tag list, and reassembles senses and examples into the presentation structure. The caller can directly pass the result to the detail component.

## WordBundle.quizDefinition() -> definition text

The word's primary definition as a quiz option or prompt shows it: every whole-word occurrence of the word's own headword (and its regular inflections) is replaced with the mask, via maskHeadword. Used by the mode 2 image captions, the mode 3 text cards and the review image captions, including their accessibility labels; each option masks its own word, so a distractor's definition masks the distractor's headword. Detail surfaces use toWordDetail, which keeps the full text.
