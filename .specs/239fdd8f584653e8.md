# AI-generated image upload and verification script

Three phases: (1) upload each generated PNG to the admin API as an image candidate, (2) CLIP-score both the new candidate and the incumbent against the word's slot-1 sentence, (3) select the generated image when it scores higher (with `pin: false` so a better candidate can still take the slot), then approve it. Direct DB access is read-only (slot-1 sentence and current selection).
